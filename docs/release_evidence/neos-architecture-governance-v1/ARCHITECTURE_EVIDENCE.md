# Architecture Evidence

The governance validator adds a read-only comparison layer between:

- Platform Core declared architecture
- NEOS observed estate state

## Invariants preserved

- Workspace composes existing NEOS intelligence.
- Project safety `UNKNOWN` remains available when evidence is incomplete.
- NEOS platform authority remains separate from workspace and dashboard surfaces.
- Workspace reads do not write portfolio or intelligence state.
- No second contract system is introduced.
- No actuator, deployment, or flashing authority is introduced.

## Determinism

The report and snapshot outputs are derived from stable declared and observed inputs so the same estate state produces the same governance snapshot fingerprint.
