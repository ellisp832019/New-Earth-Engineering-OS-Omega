# API Evidence

The `v1` service API now includes additive registry routes:

- `GET /registry`
- `GET /registry/{project_id}`
- `GET /registry/{project_id}/drift`
- `GET /registry/{project_id}/contracts`
- `GET /registry/{project_id}/identity`
- `GET /registry/{project_id}/impact`

The hardware routes remain unchanged and the API version remains `v1`.
