# Incident History Guide

Incidents are evidence-backed warnings that a historical state regressed or changed in a risky way.

## Commands

```powershell
neos flight incidents microgrow-v1 --json
neos flight regressions microgrow-v1 --json
```

## Interpretation

- incidents are records, not rumors
- regressions are indicators, not guaranteed bugs
- evidence and confidence matter more than labels
