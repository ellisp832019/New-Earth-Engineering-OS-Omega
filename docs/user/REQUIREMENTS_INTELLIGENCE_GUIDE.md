# Requirements Intelligence Guide

Requirements Intelligence is the deterministic, operator-controlled surface for traceability from intent to implementation.

## What it shows

- extracted requirement candidates from docs and requirement-shaped text
- links to feature, architecture, implementation, test, validation, release and documentation evidence
- requirement gaps
- verification readiness
- architecture components that are not yet tied to a requirement
- operator review history

## What it does not do

- it does not make canonical requirements on behalf of the operator
- it does not replace the source documents
- it does not let AI become the source of truth

## Operator actions

- `confirm` marks a requirement as canonical
- `reject` records that a candidate should not be treated as canonical
- `defer` keeps the candidate visible without promoting it

## Desktop surface

Open the `Requirements Intelligence` navigation item in the Windows desktop shell to inspect the current project payload.
