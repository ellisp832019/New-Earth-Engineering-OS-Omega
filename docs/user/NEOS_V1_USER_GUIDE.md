# Neos V1 User Guide

NEOS v1.3.0 keeps the user experience local-first, read-only, provenance-aware, and intentionally conservative.

## Covered guides

- `Hardware Centre Guide`
- `Firmware Centre Guide`
- `Registry Centre Guide`
- `Impact Analysis Guide`
- `Decision Centre Guide`
- `Portfolio Workspace Guide`

## Practical rule

Use the read-only centres to inspect evidence first, then refresh or rescan the project if the repository has changed outside NEOS.
