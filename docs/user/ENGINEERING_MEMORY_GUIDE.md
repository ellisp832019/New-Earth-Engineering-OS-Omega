# Engineering Memory Guide

Engineering Memory gives NEOS a structured history of why engineering decisions were made and what changed because of them.

## Useful commands

- `python -m neos memory build PROJECT_ID`
- `python -m neos memory show PROJECT_ID`
- `python -m neos memory timeline PROJECT_ID`
- `python -m neos memory diff PROJECT_ID`
- `python -m neos memory decisions PROJECT_ID`
- `python -m neos memory assumptions PROJECT_ID`
- `python -m neos memory experiments PROJECT_ID`
- `python -m neos memory lessons PROJECT_ID`
- `python -m neos memory milestones PROJECT_ID`
- `python -m neos memory gaps PROJECT_ID`
- `python -m neos memory contradictions PROJECT_ID`

## What the model is for

- answer why a system exists
- trace decisions through time
- expose assumptions that were never validated
- connect experiments to lessons
- find missing historical evidence
