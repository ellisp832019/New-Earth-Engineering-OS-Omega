# Portfolio Workspace Guide

The Portfolio Workspace is the desktop view for cross-project NEOS intelligence.

Use it when you want to:

- compare capabilities across projects
- inspect shared technologies
- identify reuse opportunities
- check overlap and duplication
- review portfolio risks and attention items
- search the registered ecosystem
- ask portfolio-scoped AI questions with explicit citations

If only one project is registered, the workspace will still function, but the comparisons are naturally limited to that single project.

Portfolio AI remains deterministic. It does not invent evidence and it keeps the selected project scope visible.
