# Vision and Product Strategy

## Mission

Build an engineering operating system that preserves project memory, explains system relationships, automates repetitive engineering administration and gives humans and AI agents reliable context across the complete lifecycle of a product.

## The problem

Engineering knowledge is fragmented between repositories, issue trackers, documents, CAD tools, test outputs, release notes, local notes and individual memory. Most existing tools optimize one layer. NEOS focuses on the relationships between layers.

## Product thesis

The durable value is not another AI chat interface. It is a **high-integrity engineering model** with provenance and traceability. AI becomes powerful only after the underlying project state is trustworthy.

## Product positioning

NEOS should initially be an internal engineering platform. It earns the right to become a commercial product after it has demonstrably improved real New Earth engineering work.

## Non-goals for Alpha

- Replace Git
- Replace VS Code
- Replace KiCad or CAD software
- Replace GitHub
- Replace CI systems
- Autonomously modify hardware or production systems
- Attempt perfect semantic understanding of all programming languages

## Long-term differentiation

1. Local-first project intelligence
2. Hardware + software lifecycle traceability
3. Project memory with provenance
4. Cross-version impact analysis
5. Engineering-specific AI context generation
6. Living product history
7. Multi-project reusable component intelligence
8. Human-approved automation

## Product stages

### Alpha — Understand one repository
Produce a trustworthy engineering model for one project.

### Beta — Understand a portfolio
Support multiple projects, shared components, dependencies and cross-project search.

### v1.0 — Engineering Operating System
Deliver a polished Windows desktop application, extensible plugin ecosystem, reliable AI engineering context, release intelligence, documentation intelligence and operational dashboards.

### Future — Engineering Company Intelligence
Add specialized engineering agents, experiment intelligence, digital-twin integrations and organization-wide reusable knowledge.
