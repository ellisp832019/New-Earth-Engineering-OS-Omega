# Glossary

**Canonical state** — information explicitly owned/accepted by the project.

**Derived state** — information produced by scanners, plugins or inference.

**Artefact** — a file or engineering object relevant to a project.

**Evidence** — a source supporting a claim, result or release decision.

**Knowledge graph** — nodes and relationships representing project structure and meaning.

**Project manifest** — the root machine-readable contract describing a NEOS-managed project.

**Snapshot** — a time-bounded observation of project state.

**Plugin** — an adapter adding domain-specific analysis.
