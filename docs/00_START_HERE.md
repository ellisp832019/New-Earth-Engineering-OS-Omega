# START HERE

## Purpose

This repository is the seed of New Earth Engineering OS (NEOS): a local-first engineering intelligence platform that connects source code, documentation, requirements, decisions, tests, releases, hardware evidence and AI context.

## First principle

Do not begin by building a giant UI. Build a trustworthy engineering model first.

The recommended development sequence is:

1. Establish repository truth.
2. Normalize project metadata.
3. Scan and classify artefacts.
4. Persist the knowledge graph.
5. Add semantic repository intelligence for symbols, dependencies, features, API routes, config keys and decisions.
6. Add deterministic queries, traceability and impact analysis.
7. Add AI context generation with bounded provenance.
8. Build the desktop experience on top.
9. Add plugins and multi-project intelligence.

## Definition of Alpha

Alpha is complete when NEOS can index one real project, identify its major artefacts and versions, create stable graph relationships, detect changes, and generate enough structured context that an AI assistant can answer engineering questions without blindly ingesting the entire repository.

## Do not skip

- data contracts
- migration strategy
- acceptance tests
- security boundaries
- evidence provenance
- reproducibility
- explicit handling of generated files and secrets

## First target project

The sample integration is MicroGrow, because it contains firmware, a desktop/mobile application, documentation, tests, releases and hardware-oriented engineering evidence—making it an excellent representative project for the NEOS Alpha model.
