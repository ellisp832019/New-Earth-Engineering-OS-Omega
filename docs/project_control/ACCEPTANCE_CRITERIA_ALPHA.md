# Alpha Acceptance Criteria

NEOS Alpha is accepted only when all critical criteria pass:

- Clean setup on supported Windows host.
- CLI doctor healthy.
- Database initializes deterministically.
- Manifest validation rejects malformed required fields.
- Real MicroGrow repo can be scanned read-only.
- Common secret files are excluded.
- File hashes are stable.
- Unchanged rescan does not fabricate changes.
- Basic project summary is useful.
- Tests pass.
- Backup/restore is demonstrated.
- Known limitations documented.
