# NEOS v1.1.0 GitHub Release Draft

## Title

NEOS v1.1.0 - Hardware & Physical Engineering Intelligence

## Summary

This release packages deterministic hardware discovery, hardware routes, hardware CLI commands, and Hardware Centre support into the Windows build.

## Installation

Download the Windows release bundle, unzip it, and launch `NEOS.exe`.

## Upgrade Notes

- keep the existing local database
- replace the old `v1.0.0` bundle with the new `v1.1.0` bundle
- re-open Hardware Centre after refreshing projects that changed on disk

## Package Asset

- `New-Earth-Engineering-OS-Windows-v1.1.0.zip`

## Known Limitations

- read-only hardware evidence only
- no embedded firmware intelligence yet
- no electrical certification claims

## Security

- localhost-only service
- no cloud dependency
- no external hardware upload flow
