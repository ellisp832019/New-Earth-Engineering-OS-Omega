# Evidence Retrieval

Evidence retrieval is deterministic and project scoped.

## Ranking Signals

- direct token match
- intent match
- relationship relevance
- recency
- scan/snapshot recency
- confidence from canonical records

## Citation Strategy

Every AI response can surface citations that point back to specific NEOS evidence items.

## Raw File Fallback

Raw repository text is only used as bounded evidence and is treated as untrusted input.
