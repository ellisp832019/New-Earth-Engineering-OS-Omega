# Experiment Memory

Experiment Memory captures explicit engineering experiments and the evidence around them.

## Fields

- id
- title
- hypothesis
- setup
- inputs
- procedure
- result
- outcome
- status
- source evidence
- related features
- related hardware
- related decisions
- lessons

## Statuses

- planned
- running
- passed
- failed
- inconclusive
- abandoned

## Rule

Do not fabricate experiments from code changes.
