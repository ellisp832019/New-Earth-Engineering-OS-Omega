# Regression Intelligence

Regression intelligence turns deterministic state changes into indicators, not accusations.

## Example indicators

- test count decreases
- API removed
- maturity decreases
- known unknowns increase
- risk count increases
- release evidence disappears

## Incident model

Incidents are evidence-backed records that may be created from regression indicators when the signal is strong enough.

## Safe interpretation

An indicator is not automatically a bug. It is a clue that something changed and deserves review.
