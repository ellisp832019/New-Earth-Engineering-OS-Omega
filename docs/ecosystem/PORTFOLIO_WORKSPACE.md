# Portfolio Workspace

The desktop Portfolio Workspace is the NEOS v0.7 cross-project entry point.

It exposes:

- project registry and aggregate health
- capability matrix
- technology matrix
- reuse workbench
- overlap intelligence
- dependency map
- portfolio risks
- attention items
- timeline history
- search
- portfolio AI with explicit project scope

The workspace is intentionally deterministic. If only one project is registered, the workspace still renders, but cross-project comparison remains limited and should be labeled as such.
